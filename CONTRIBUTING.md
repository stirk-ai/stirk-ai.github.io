# Contributing

Thanks for helping improve Stirk AI.

1. Fork the repository and create a focused branch.
2. Make the smallest clear change that solves the problem.
3. Test the website locally and check responsive behavior.
4. Keep documentation, links, and accessibility details up to date.
5. Open a pull request with a concise description and verification notes.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md) and read [SECURITY.md](SECURITY.md) before reporting sensitive issues.

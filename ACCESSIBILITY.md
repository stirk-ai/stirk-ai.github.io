# Accessibility

Stirk AI aims to keep its website usable by as many people as possible. The site uses semantic HTML, keyboard-friendly controls, readable contrast, responsive layouts, alternative text for meaningful images, and theme-aware presentation.

If you find an accessibility barrier, please open an issue in the [website repository](https://github.com/stirk-ai/stirk-ai.github.io) with the page, device, browser, and steps to reproduce.
